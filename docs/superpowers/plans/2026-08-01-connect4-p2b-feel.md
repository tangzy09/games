# connect4 P2b：手感与可读性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「能玩」变成「好玩」——让**落子这一个动作**爽到极致，让**只有高手才读得出的局面**变成一眼可见的事件，并把**输**变成不疼的。

**Architecture:** 纯前端表现层，**不碰任何真值逻辑**。动画/音效/震动挂在既有的 `renderAll()` 契约与 `dispatch()` 上；音效用 `tools/gen-sfx.js` **零外部素材合成 wav**（照 `games/snake/tools/gen-sfx.js`），经 `engine/audio.js` 的 `Sfx`/`Haptics` 播放。

**Tech Stack:** 引擎 `engine/audio.js`（`Sfx` 池 / `Haptics` 含 Capacitor 插件 + vibrate 兜底 / `restoreAudioPrefs`）· canvas 逐帧动画 · Playwright 截图 + 像素判据。

**规格：** `games/connect4/DESIGN.md`（权威）。**动手前必读 §6.3–§6.6、§6.8、§6.9，以及 §9.2 的断崖与产品判断。**

## Task 2：`js/fx.js` + 落子物理下落

**Files:** Create `games/connect4/js/fx.js` · `games/connect4/tests/test-fx.js`；Modify `js/render.js`、`js/main.js`、`index.html`、`package.json`

DESIGN §6.3：**一局落 20 次子，这一个动作的手感就是这个游戏的手感。**
加速下落 → 撞底/撞上一枚 → **微弹** → 停（带一点 squash & stretch）。

- [ ] **Step 1：先写 `test-fx.js`（纯逻辑，node 可测）**
`fx.js` 只暴露**纯函数式的状态推进**：`start(kind, params)` / `step(dtMs)` / `pose()` / `done()`。这样动画曲线可以在 node 里断言，不用起浏览器。
必须断言：落点**恰好停在目标格**（不许超调后停在半格）· 总时长在预算内 · `step` 是**幂等于 dt 的**（同一段 dt 分两次推进，结果与一次推进相同——⚠ 否则掉帧会让动画走偏）。

- [ ] **Step 2：⛔ 动画期间不许锁输入**
本仓铁律（casual-game-meta §6）：**输入只在「霸屏动画」时锁**；落子动画期间点击必须照常生效，否则快手玩家觉得「点不动」（solitaire 实踩：发牌动画 1 秒内点击全被吞）。

- [ ] **Step 3：接 `renderAll()`**
⚠ 引擎契约是**每帧 `clearHits()` 重画全屏**。动画要靠 `requestAnimationFrame` 驱动重画，⛔ 但**没有动画在跑时必须停下来**（别空转烧电）。

- [ ] **Step 4：接音效 + 震动**
落定时播对应深度的 `land*` + `Haptics`。⚠ 读 `engine/audio.js` 的真实 `Haptics` 签名。

- [ ] **Step 5：⭐ 像素验收**
E2E 里连拍三帧，断言**棋子的 y 坐标确实在变**（⛔ 别只断言「动画标志为 true」）。
